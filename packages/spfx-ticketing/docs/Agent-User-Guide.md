# Agent User Guide

## Ticket-Cockpit
- Tabs zur Filterung: Meine Tickets, Unzugewiesen, Überfällig, Wartet auf Kunde, Wartet auf Außendienst, Erledigt.
- Suche über Ticket-ID oder Betreff.

## Ticket-Detail
- Ticket-Header und Timeline prüfen.
- Antwort-Panel:
  1. Kategorie und Template auswählen.
  2. Betreff und Vorschau prüfen.
  3. Freitext ergänzen.
  4. Empfänger wählen (Kunde, Außendienst, Manuell).
  5. Senden.

## Interne Notizen
- Interne Notizen werden nicht per E-Mail verschickt.
- Für Team-Kommentare nutzen.

## Statuspflege
- Nach Senden wird der Status automatisch auf „Wartet auf Kunde“ gesetzt.
- Statusänderungen können bei Bedarf über die Ticketliste erfolgen.
